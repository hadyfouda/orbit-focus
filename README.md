# Orbit — رحلة التركيز 🛰

لعبة استكشاف فضاء هادية بتشتغل مع وقت تركيزك:
**الرحلة = وقت الشغل**، و**الهبوط على الكوكب = البريك**.

تطبيق ويب (PWA) بيتثبت على الموبايل زي أي تطبيق، بيشتغل Offline بالكامل، وكل التقدم متخزن على جهازك.

## إزاي بتتلعب

1. **خريطة المجرة:** اختار كوكب مجهول. كل دايرة على الخريطة هي مدة الرحلة (15 / 25 / 35 / 45 / 60 دقيقة).
2. **الرحلة:** دوس "انطلاق" وارجع لشغلك. التايمر شغال حتى لو قفلت التاب، والسفينة بتشحن طاقة الروفر طول الرحلة.
3. **الهبوط (البريك):** أول ما توصل يظهر لك Orbit Reached. انزل واكشف شبكة 5×5 مغطية بالضباب. كل مربع بيستهلك خطوة طاقة.
   - موارد: تيتانيوم، كريستال، مادة مظلمة
   - كائنات ونباتات وحفريات بتتسجل في الموسوعة بدرجات ندرة (Common لحد Legendary)
   - ظواهر غريبة بتطلع لك كارت بقرارين (مخاطرة أو آمن)
   - مخاطر بتسحب من الدرع، ولو الدرع خلص بترجع بنص الحمولة بس
4. لما وقت البريك يخلص، الروفر بيرجع أوتوماتيك. **ارجع لشغلك.**
5. **الورشة:** طوّر المحرك (مسافات أبعد وكائنات أندر)، والرادار (يكشف السطح قبل ما تنزل)، والروفر والدروع (خطوات أكتر وكواكب أخطر).

## الرفع على GitHub Pages (مجاناً)

### من الموبايل أو المتصفح، من غير أي أوامر
1. اعمل حساب على [github.com](https://github.com) لو معندكش.
2. **New repository** ← سمّيه مثلاً `orbit` ← خليه **Public** ← Create.
3. في صفحة الـ repo: **Add file ← Upload files** ← ارفع **كل الملفات والفولدرات** (`index.html`، `sw.js`، `manifest.webmanifest`، وفولدرات `css` و`js` و`icons`) ← **Commit changes**.
   > لازم `index.html` يبقى في أول مستوى في الـ repo، مش جوه فولدر.
4. **Settings ← Pages** ← تحت Source اختار **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
5. استنى دقيقة أو اتنين، واللينك هيظهر بالشكل ده:
   `https://USERNAME.github.io/orbit/`

### أو بالـ Terminal
```bash
cd orbit-focus
git init
git add .
git commit -m "Orbit v1.0"
git branch -M main
git remote add origin https://github.com/USERNAME/orbit.git
git push -u origin main
```
وبعدين فعّل Pages من الإعدادات زي الخطوة 4.

## التثبيت على الموبايل

- **Android (Chrome):** افتح اللينك ← هتظهر رسالة "Install app"، أو من قايمة ⋮ اختار **Install app / Add to Home screen**. وكمان في زرار تثبيت جوه التطبيق في تاب "السجل".
- **iPhone (Safari):** افتح اللينك ← زرار المشاركة ← **Add to Home Screen**.

بعد التثبيت هيفتح بشاشة كاملة ويشتغل من غير إنترنت.

## تحديث التطبيق بعد أي تعديل

غيّر رقم الإصدار في أول سطر في `sw.js`:
```js
const CACHE = 'orbit-v1.0.1';
```
وارفع الملفات تاني. الأجهزة هتاخد التحديث في المرة الجاية اللي تفتح فيها التطبيق (وأحياناً محتاج تقفله وتفتحه مرتين).

## ملاحظات مهمة

- **الإشعارات:** المتصفحات مش بتسمح لموقع يبعت إشعار في وقت محدد وهو مقفول من غير سيرفر. علشان كده إشعار "وصلت" بيشتغل لما التطبيق مفتوح في الخلفية. لو قفلته خالص، التايمر بيتحسب صح ولما تفتح هتلاقي نفسك في المدار.
- **وضع التجربة** (من تاب السجل): الدقيقة بتبقى ثانية في الرحلة، علشان تجرب اللعبة بسرعة. الرحلات دي مش بتتحسب في وقت التركيز.
- **النسخ الاحتياطي:** التقدم متخزن في المتصفح. لو مسحت بيانات المتصفح هيتمسح، فخد **تصدير نسخة** من تاب السجل كل فترة.
- لو فتحت `index.html` مباشرة من الجهاز (`file://`) اللعبة هتشتغل، بس التثبيت والـ Offline محتاجين تفتحه من لينك (GitHub Pages أو أي سيرفر).

## هيكل الملفات

```
index.html            الصفحة الرئيسية
css/style.css         التصميم (Sci-Fi Terminal، Dark Mode)
js/data.js            أنواع الكواكب، الصفات، الموسوعة، والأحداث
js/app.js             منطق اللعبة والواجهة
sw.js                 Service Worker للـ Offline
manifest.webmanifest  إعدادات التثبيت
icons/                الأيقونات
```

### عايز تضيف أحداث جديدة؟
افتح `js/data.js` وزوّد عنصر جديد في `EVENTS` بنفس الشكل. التأثيرات المتاحة:
`ti` / `cr` / `dm` (موارد)، `energy`، `shield`، `reveal` (يكشف مواقع)، `spec` و`art` (اكتشاف جديد في الموسوعة).
